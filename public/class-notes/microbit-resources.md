## Common Micro:bit Features

### 📱 Built-in Hardware

- **25 LEDs**: Arranged in a 5×5 grid for display
- **2 Buttons**: A and B for user input
- **Accelerometer**: Detects movement, tilt, shake
- **Magnetometer**: Acts as a compass
- **Temperature sensor**: Measures ambient temperature
- **Light sensor**: Uses LEDs to detect light levels
- **Radio**: Communicates with other Micro:bits
- **Bluetooth**: Connects to phones and computers
- **Speaker**: Plays sounds (on newer models)
- **Microphone**: Records sounds (on newer models)

### 🔌 External Connections

- **GPIO pins**: Connect external components
- **3V and GND**: Power for external devices
- **I2C**: Connect advanced sensors
- **SPI**: High-speed communication
- **USB**: Programming and power
